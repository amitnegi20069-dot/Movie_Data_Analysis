# 🎬 Movie Data Analysis

Welcome to the **Movie Data Analysis** project! 🍿
This project explores a dataset of movies to uncover interesting trends, popular genres, and audience voting patterns using Python and Data Visualization libraries.

## 📝 Project Overview
The goal of this project is to perform Exploratory Data Analysis (EDA) on movie data. By cleaning the data and creating visual plots, we dive deep into finding what makes a movie popular and how different genres contribute to the film industry.

## 📊 Key Features & Analysis
In this Jupyter Notebook, we explored the following:
* **Data Cleaning:** Handling missing values, cleaning column names, and fixing data types (e.g., converting strings to datetime/numeric).
* **Popularity Insights:** Finding the most and least popular movies in the dataset.
* **Genre Trends:** Visualizing the Top 15 most frequent genre combinations using Seaborn.
* **Vote Distribution:** Categorizing and plotting the distribution of audience vote averages.
* **Release Timelines:** Analyzing movie releases over time using histograms.

## 🛠️ Tech Stack Used
* **Python** 🐍
* **Pandas** (Data Manipulation & Cleaning)
* **Matplotlib & Seaborn** (Data Visualization)
* **Jupyter Notebook** (Code Environment)

## 📂 Dataset Information
The dataset contains information about various movies, including:
* `Title` & `Overview`
* `Release_Date`
* `Popularity` & `Vote_Average`
* `Genre` & `Original_Language`
* `Poster_Url`
